> [!IMPORTANT]
> **VelvetCart** is a modern, responsive **E-Commerce Admin Dashboard** styled in a **Purple, Pink, and Lavender** palette—featuring Light & Dark modes, live revenue tracking, editable admin profile, and automatic `localStorage` saving.

## 💖 Key Features & Functionality

> [!TIP]
> Everything updates in real time without a database—all changes stay saved in your browser!

* 💜 **Dual Aesthetic Theme (Light & Dark Mode):** Switch smoothly between **Soft Lavender Light Mode** (`#f3e8ff`) and **Midnight Plum Dark Mode** (`#1a1025`), with automatic theme persistence.
* 🩷 **Editable Admin Profile:** Click the top-right profile chip or sidebar link to edit the **Admin Name** and **Role**—instantly updates the *"Welcome, [Name] ✨"* greeting and avatar badge.
* 🛍️ **Complete Order Management (Add & Delete):** Create new orders with **Customer Name**, **Product Name**, **Amount (\$)**, and color-coded status badges (`Pending`, `Shipped`, `Delivered`), or remove orders with one click.
* 📊 **Real-Time KPI Summary Cards:** Live calculation of **Total Revenue**, **Total Orders**, and **Pending Orders** whenever orders change.
* 🔍 **Instant Live Search:** Filter the orders table immediately by typing a customer or product name.
* 📱 **100% Responsive Design:** Adapts cleanly across desktop, tablet, and mobile screens with a collapsible navigation menu.


   ```bash
   cd e-commerce-admin-portal
   ```

3. **Open in browser:**
   Launch `index.html` directly or via **Live Server** in VS Code.
