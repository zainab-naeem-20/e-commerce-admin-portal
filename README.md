## ✨ About The Project

**VelvetCart Admin Portal** is a modern and user-friendly dashboard designed to manage an online store's orders and administrator profile.

It features a beautiful purple and pink interface, order management tools, real-time dashboard statistics, a searchable orders table, and a dark mode option.

The dashboard uses browser `localStorage` to save orders, admin details, and theme preferences.

## 🚀 Features

- 📊 **Dashboard Overview** — View total revenue, total orders, and pending orders.
- 🛍️ **Order Management** — Add new customer orders with product names, prices, and statuses.
- 📦 **Order Status Tracking** — Manage Pending, Shipped, and Delivered orders.
- 🔍 **Search Orders** — Search orders by customer name or product name.
- 🗑️ **Delete Orders** — Remove unwanted orders from the dashboard.
- 👤 **Admin Profile Management** — Update the administrator's name and role.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 💾 **Local Storage** — Save order data, admin details, and theme preferences in the browser.
- 📱 **Responsive Layout** — Mobile-friendly navigation and dashboard layout.
- 📅 **Current Date** — Automatically displays the current date.

## ⚙️ Getting Started

Follow these steps to run VelvetCart locally.

**1. Clone the repository**

```bash
git clone https://github.com/zainab-naeem-20/e-commerce-admin-portal.git
```

**2. Open the project folder**

```bash
cd e-commerce-admin-portal
```

**3. Run the project**

Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a smoother development experience.

## 💾 Data Storage

VelvetCart currently uses browser `localStorage` to retain:

- Order information
- Administrator name
- Administrator role
- Selected theme preference

**Note:** This is a frontend project. It does not currently include a backend, database, or server-side authentication. Stored data remains in the browser where the project is used.
